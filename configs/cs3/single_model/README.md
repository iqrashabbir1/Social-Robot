# Single-Model CS3 GPU Configs

These configs run one GPU model at a time so you can inspect:
- training curves
- validation behavior
- convergence speed
- latency
- resource usage

Available configs:
- `deep_small_gpu.yaml`
- `deep_medium_gpu.yaml`
- `deep_wide_gpu.yaml`
- `transformer_light_gpu.yaml`
- `transformer_medium_gpu.yaml`
- `transformer_wide_gpu.yaml`
