# Introduction

Cognitive caregiving robots are increasingly discussed as assistive platforms for elderly and homecare settings, but many systems still join perception, control, and evaluation in ad hoc ways that make rigorous benchmarking difficult. For a caregiving robot to become scientifically credible, the sensing stack must be synchronized, the digital twin must be measurable, and the affect pipeline must be benchmarked under conditions that reflect multimodal robot operation rather than standalone computer-vision evaluation.

This Paper 1 focuses on the infrastructure layer required before later caregiving intelligence modules can be studied credibly. The first requirement is a measurable ROS2 and digital-twin backbone. Without timestamped topic interfaces, replay support, and disturbance analysis, later modules such as intervention planning or explainable reasoning cannot be evaluated under controlled runtime conditions. The second requirement is a multimodal sensing and synchronization pipeline that can align video, audio, robot context, and optional physiology into consistent windows while documenting missing-modality behavior. The third requirement is an emotion-recognition benchmark that preserves the existing repository baseline and extends it toward multimodal benchmarking without overstating the evidence when aligned real-world datasets are not yet available.

Paper 1 therefore contributes a ROS2 digital-twin experiment scaffold, a synchronized multimodal data pipeline, and a reproducible benchmark workspace for emotion recognition. The repository separates implemented real baseline evidence from synthetic placeholder multimodal experiments and explicitly records what still requires real robot or site data. This makes the codebase suitable for a publication-oriented first paper while preserving a clean path toward later case studies.
