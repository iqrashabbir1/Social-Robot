# Updated Introduction

Cognitive caregiving robots need a measurable runtime backbone before they can support strong downstream claims. Perception models alone are not enough: the system also needs synchronized multimodal sensing, digital-twin state tracking, controlled replay, and benchmark logic that can be reproduced and audited. Paper 1 therefore focuses on framework validation rather than deployment outcomes.

The updated repository supports three tightly scoped studies. CS1 is a simulation-first and playback-grounded digital-twin study. CS2 is a multimodal synchronization study with both synthetic streams and a small real local anchor. CS3 is a preliminary emotion-benchmark study that preserves the existing baseline, adds multiple trainable algorithms including XGBoost, and clearly distinguishes pilot demonstrations from synthetic benchmark evidence.

This framing is intentionally conservative. The paper should argue that the repository now offers a technically defensible foundation for later real simulator and robot studies, not that it already demonstrates caregiving performance in the field.
