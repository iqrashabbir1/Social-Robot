# Claim Boundaries

## Valid claims
- The repository provides a simulation-first and ROS2-compatible framework for Paper 1.
- CS1 includes simulation-based and playback-grounded technical validation.
- CS2 includes both synthetic synchronization experiments and a small pilot real-anchor session.
- CS3 includes a preserved baseline, an enabled XGBoost path, and preliminary multimodal benchmarking.

## Invalid claims
- The system is not clinically validated.
- The system is not a live deployed caregiving robot.
- The current pilot real-anchor data are not sufficient to claim dataset generalization.
- The ROS2 path on this machine is not a full live ROS2 runtime; it is playback-grounded through a ROS2-compatible fallback.

## Exact wording to prefer
- “simulation-first”
- “ROS2-compatible”
- “playback-grounded”
- “pilot real-anchor”
- “benchmark preliminary”
- “deployment not claimed”
