# Reviewer Defense Notes

## If asked whether the system is deployed
Answer: no. The paper is simulation-first and playback-grounded, not a deployment paper.

## If asked whether the multimodal models were trained on real caregiving data
Answer: no. The trainable multimodal comparisons are still preliminary and mostly synthetic.

## If asked why include a real anchor at all
Answer: to show that the synchronization and baseline inference paths can be grounded on real local sensor data without overstating dataset scale.

## If asked whether ROS2 is truly running
Answer: on this machine, full ROS2 is unavailable on `PATH`, so the paper uses a ROS2-compatible playback pathway and labels it accordingly.

## If asked why the paper is still worthwhile
Answer: because it provides a reproducible technical substrate with explicit claim boundaries, which is valuable before larger real robot studies.
